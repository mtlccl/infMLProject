# Classificação Binária com Modelos Supervisionados

Este projeto foi desenvolvido como parte da disciplina de **Machine Learning** do curso de pós-graduação em Inteligência Artificial no **Infnet**. O foco principal é a estruturação, treinamento, avaliação e interpretação de modelos supervisionados clássicos para um problema de classificação binária.

## 🚀 Tecnologias Utilizadas

* **Python 3.10+**
* **Pandas & NumPy:** Manipulação e análise de dados.
* **Scikit-Learn:** Implementação dos modelos de ML e métricas de avaliação.
* **Matplotlib & Seaborn:** Visualização de dados e matrizes de confusão.
* **Jupyter Notebook:** Ambiente de desenvolvimento e experimentação.

## 📊 Modelos Implementados

O projeto explora a evolução de modelos simples para arquiteturas de conjunto (Ensembles):

1. **Perceptron:** Modelo linear de base para entender a separabilidade inicial dos dados.
2. **Árvore de Decisão:** Modelo não-linear para capturar relações e divisões mais complexas no dataset.
3. **Ensembles (Random Forest / Gradient Boosting):** Utilização de múltiplas árvores para reduzir o *overfitting* e maximizar a acurácia do modelo final.
